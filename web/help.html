网络工具 1.2.3 · Windows / macOS

桌面网络工具箱，独立窗口运行（Windows / macOS）。关闭窗口会隐藏到托盘或后台并保持运行；网页在软件内打开。免安装，一般免管理员权限。数据只保存在本机。实时抓包在 Windows 上需要自行安装 Npcap，部分环境可能需要管理员权限；打开 pcap 文件不需要。

快速开始

1双击程序Windows 运行「网络工具.exe」，macOS 打开「网络工具.app」（或源码下的 python app.py），会打开独立桌面窗口，不再依赖系统浏览器。
2关闭留在托盘点减号（macOS 为黄灯）会最小化到任务栏 / Dock，可再点图标恢复。点关闭才会隐藏到托盘或菜单栏并保持运行。彻底退出请用托盘 / 菜单栏「退出」或「设置 → 退出程序」。
3选工具运行点九宫格进入工具，或用标题栏「搜索工具」按名称/英文过滤。填参数后点「开始」；实时输出可随时「停止」。
4复位与导出「清空」复位结果；「导出」把参数、指标、表格、日志、二维码保存为 HTML 报告。

服务只监听 127.0.0.1，不对局域网开放。运行日志与配置在 Windows 的 %LOCALAPPDATA%\网络工具\，或 macOS 的 ~/Library/Application Support/网络工具/，不会在程序旁边创建 data 文件夹。托盘或菜单栏可「打开窗口」或「退出」（退出会彻底结束进程）。需要打开的外部网页（例如三网拨测）会在软件内弹出子窗口，不会跳到系统浏览器。

1.2.3 有什么变化

  • 抓包分析：新增类 Wireshark 的三栏视图。上方是报文列表（序号、时间、源/目的地址、协议、长度、Info），点击一行选中该包；中间是 Packet Details，按 Frame / Ethernet / IPv4 或 IPv6 / TCP、UDP、ICMP / ARP / DNS / HTTP 以及常见 TLS 握手字段（记录类型、版本、SNI）逐层展开，解不出的字段会标明「未解出」；下方是十六进制 + ASCII 字节，点选字段会尽量高亮对应范围。三栏在同一页内同屏可见，可拖动调整高度。可用显示过滤按协议、地址、端口或关键字缩小列表。
  • 离线与实时：可打开 / 保存 .pcap，也能读取常见 .pcapng（结构过复杂时会提示另存为经典 pcap）。打开文件不依赖 Npcap 或管理员权限。实时抓包可列出网卡、设置 BPF 过滤（预置 tcp、udp、icmp、dns、http、tls/443、arp）、开始 / 停止 / 清空。默认最多保留 10000 个包，超限可丢弃最旧或停止并提示。支持按协议统计、会话/对端汇总，以及跟踪 TCP 流（按四元组重组 payload）。
  • 不内置 Npcap、流量不上云：Windows 实时抓包请到 https://npcap.com/ 自行安装 Npcap（本程序不随包装该组件）。未安装或缺少权限时，界面会说明原因，仍可做离线分析。macOS 使用系统 libpcap，若缺少 /dev/bpf* 权限会同样提示。抓包不会自动开始；流量只在本机分析。明文协议可能含账号、密码或 Cookie，请仅分析你有权查看的流量。

1.2.2 有什么变化

  • 修复 Windows 无法启动：v1.2.1 误把 PNG 当作窗口/托盘图标传给系统，进程会在启动时静默退出。1.2.2 在 Windows 上只使用 .ico；托盘图标先经 Pillow 转为位图。图标失败会跳过图标继续打开窗口，异常写入运行目录下的 logs/app.log。
  • 崩溃后可再次打开：若上次异常退出留下了单实例锁，但进程已结束或服务无响应，会自动接管，不会再点一次毫无反应。
  • macOS 启动防护：打包并优先使用 app.icns，避免把 Windows .ico 直接交给 Cocoa。菜单栏托盘在主窗口就绪后再创建，失败不影响 Dock 与主界面。

1.2.1 有什么变化

  • 减号最小化到任务栏 / Dock：点窗口「减号」（macOS 为黄灯）只做普通最小化，窗口留在任务栏或 Dock，再点图标即可恢复。不再隐藏到托盘，也不会从任务栏 / Dock 消失。已去掉「最小化运行」开关。
  • 关闭才进后台：点「关闭」仍然隐藏到托盘（Windows）或菜单栏 / 后台（macOS）并保持运行；只有托盘或菜单栏「退出」，或「设置 → 退出程序」，才会彻底结束进程。开机自启会正常显示主窗口。
  • 标题栏搜索工具：在「设置」左侧增加「搜索工具」输入框，可按中文名称或常见英文（如 ping、ssh）即时过滤主界面图标。清空后恢复全部；在搜索框按 Enter 若只剩一项则打开该工具，Esc 清空。
  • 新增 macOS 版：提供 Apple Silicon（arm64）压缩包，并尝试构建 Intel（x64）。包未经 Apple 公证，第一次请按住 Control 点击「打开」，或到「隐私与安全性」允许。SSH、服务器信息提取、搜索栏、关闭进后台可用。「Windows 诊断」「WLAN 分析」仅 Windows 显示。网卡叠加在 Mac 上使用源地址绑定 + IP_BOUND_IF，不接管系统代理。配置在 ~/Library/Application Support/网络工具/。

1.2.0 有什么变化

  • 最小化运行默认开启：最小化时隐藏到托盘，可在「设置」中关闭。
  • 关闭窗口默认留在后台：不再提供「保留后台运行」开关。关闭窗口一定隐藏到托盘并保持运行；只有托盘「退出」或设置里的「退出程序」才会结束进程。读取旧版 settings.json 时也会按这个行为执行。
  • 开机自启：若同时开启了「最小化运行」，登录 Windows 后会先进入托盘。
  • 网页在软件内打开：例如「三网拨测」会新开一个软件内窗口访问阿里云拨测页（该页禁止 iframe，所以不用嵌入），关闭子窗口不影响主程序。主窗口仍是本机界面，不会被导航到外部站点。
  • 已删除「分享软件」：原先置灰的手机端入口已去掉。
  • 网卡叠加：连接级多网卡聚合。选择多张网卡后启动本机 HTTP / SOCKS5 代理，每条新连接绑定到一张网卡。可选接管当前用户系统代理；停止或退出时恢复。适合多连接下载，不能把单条 TCP 测速变成多条链路之和。
  • 服务器信息提取：把告警 / CMDB 原文解析成主机名、SN、管理 IP、BMC、型号、机房、故障，并生成「【合营云】区域Server业务主机名硬件故障」标题，支持一键复制。用粘贴或读剪贴板，没有「从当前浏览器页提取」。
  • SSH：软件内终端。可保存 / 编辑 / 删除常用主机（名称、地址、端口、用户名）。密码默认不保存；「记住密码」在 Windows 用当前用户 DPAPI 加密，在 macOS 用本机 Fernet 密钥加密，默认关闭。私钥只引用本机路径。
  • 其它新工具：路由表、ARP 表、网卡流量、NAT 类型检测。

AI 分析（可选）

任意工具跑完后，点「AI分析」，会把当前工具的参数、指标、表格和日志发给已配置的大模型，返回【结论】【依据】【建议】。点右上角「AI 设置」配置接口。

  • 支持 OpenAI 兼容接口：阿里云百炼、DeepSeek、OpenAI、本地 Ollama 等，可选择预设后自动填入地址和模型。
  • API Key 仅保存在本机 %LOCALAPPDATA%\网络工具\config\ai.json；分析时只发送当前工具输出。
  • 「Windows 诊断」可填「AI 关注问题」（如开机慢、磁盘 100%、蓝屏），AI 会围绕该问题深度分析；留空则做全局深度分析。
  • 「网络诊断」每个阶段现在有分隔标题（1/6 本机信息 … 6/6 完成），日志较长时更容易定位。

功能清单

Windows 共 48 项（「WLAN 分析」仅检测到无线网卡时显示）；macOS 不显示「Windows 诊断」和「WLAN 分析」；需联网 表示依赖外部接口或目标站点。每项运行结果都可点「导出」保存为自包含 HTML（参数、指标、表格、日志、二维码）。

常见排查场景

网页打不开 / 很慢
  1. 「网络诊断」输入域名，先看 DNS 是否解析、TCP 是否通、traceroute 卡在哪一跳。
  2. 能解析但慢：用「HTTP速度」看是 DNS、TCP、TLS 还是首字节耗时。
  3. 怀疑证书：用「服务器探测」看到期天数与颁发者。
间歇丢包 / 抖动
  1. 「超级Ping」同时盯网关、内网 DNS、公网 DNS、目标，判断丢在内网还是出口。
  2. 「MTR」看逐跳丢包率，定位具体节点。
端口不通
  1. 「TCPing」或「telnet」验证单端口握手与 Banner。
  2. 「端口探测」扫一组端口；「端口占用」确认本机是否被别的进程占用。
VPN / 隧道下能 ping 通但打不开网页
  1. 「MTU测试」对比直连与隧道下的路径 MTU，确认是否分片被丢。
排查局域网设备
  1. 「扫描局域网」列出存活设备与 MAC；「IP扫描」可指定其它网段。
  2. 需要远程开机时用「唤醒」发魔术包。
报障 / 工单取证
  1. 「网络诊断」跑完后点「导出配置包」，一键生成 txt（含 ipconfig、路由、ARP、netstat、代理、防火墙）并下载。
  2. 合营云硬件故障工单：把告警或 CMDB 原文贴进「服务器信息提取」，生成标题和七行模板后一键复制。
想把有线和 Wi-Fi 一起给下载器用
  1. 打开「网卡叠加」，勾选要参与的网卡；Windows 上可开启「接管系统代理」，macOS 请在应用中手动填写本地代理，再点「启动聚合」。
  2. 用浏览器或多连接下载工具测试。单线程测速通常不会明显变快，这是正常现象。
  3. 用完后点「停止聚合」，系统代理会恢复。
连到服务器里操作
  1. 打开「SSH」，填写地址、端口、用户名和密码（或私钥路径）后点「连接」。
  2. 需要下次再用时，先改好备注名，点「保存主机」。之后可在列表里「填入并连接」。
查看或分析抓到的包
  1. 打开「抓包分析」。若只需看已有文件，点「打开 pcap」，不需要 Npcap 或管理员权限。
  2. 若要实时抓包：Windows 先安装 Npcap（https://npcap.com/），必要时以管理员运行；macOS 若提示 BPF 权限不足，用管理员权限运行。选择网卡和过滤条件后点「开始抓包」，不会自动开始。
  3. 在列表中点一条报文，中间查看逐层字段，下方对照原始字节。可用「跟踪 TCP 流」重组会话，「统计」查看协议与对端汇总。

已知限制

  • Ping / traceroute / MTR 仍通过系统 ping / tracert 实现，一般免管理员权限；个别设备屏蔽 ICMP 时会显示超时，可改用 TCPing。
  • 「抓包分析」的实时抓包通过系统 libpcap / Npcap，不会自动开始，也不把流量上传。Windows 不内置 Npcap，未安装时只能打开 pcap 做离线分析。默认最多保留 10000 个包，以免占用过多内存。明文协议可能含密码或 Cookie，请仅在本机分析。
  • 测速、IP 归属、Whois、全国 DNS 等依赖外网接口，公司代理或防火墙可能拦截；失败会明确提示，不影响本地功能。
  • UDP 端口扫描无回包不代表关闭，工具不做判定；只做 TCP 连接扫描。
  • IPv6 需要本机与出口都支持；不支持时显示「不支持 IPv6 或超时」。
  • iperf3 需要可访问的 iperf3 服务端；公网 5201 端口常被网络策略阻断，优先用内网服务端。
  • 「扫描局域网」会过滤代理 ARP、组播和占位 MAC；跨网段设备不会被发现。
  • 「网卡叠加」是连接级分配，不是虚拟网卡 / TUN，也不是真正的链路聚合；同一出口下的多张网卡无法把单连接带宽叠加。
  • 「SSH」首次连接会自动接受主机密钥（保存在本机配置目录）。记住密码仅当前系统用户可解密，仍请避免在公用电脑上勾选。
  • 诊断包会包含本机网络配置（IP、MAC、路由、连接列表），外发前请确认是否符合内部数据规范。

技术说明

Python 3.13 / Flask 本地服务 + pywebview 桌面窗口（Windows 用 WebView2，macOS 用 WKWebView）；长任务用 SSE 流式推送。点减号最小化到任务栏 / Dock；点关闭会隐藏到托盘或后台并保持运行。标题栏可搜索工具。外部网页在软件内的子窗口打开。

Windows 打包单个 exe：powershell -ExecutionPolicy Bypass -File build.ps1。macOS 打包 .app 并生成 zip：bash build-macos.sh。macOS 包未签名，第一次需右键「打开」。

powershell -ExecutionPolicy Bypass -File build.ps1

iperf3 会依次在 PATH、程序目录、_MEIPASS 中查找 bin/iperf3.exe。旧版若在 exe 旁残留 data 目录，首次启动会把 ai.json 和日志迁移到 LocalAppData。
